# Project archive

These documents preserve requirements and dated evidence from completed work.
They are historical records, not current setup or operating instructions.
Use [setup](../setup.md) and [operation](../operation.md) for current commands,
and the [commissioning checklist](../development/vehicle-commissioning-checklist.md)
for unfinished physical-car work.

- [Original Round 1 plan](round1-plan.md): intended scope and acceptance targets;
  inclusion in the plan does not establish completion.
- [Simulation validation](simulation-validation.md): scenario, perception and
  launch observations, with the limits of sampled checks and simulated feedback.
- [Software validation](software-validation.md): real-car adapter, sensor and
  dashboard checks, including what was not tested on physical hardware.

Completed plans, comparisons and session audits have been consolidated into
these records and the current technical references. Git retains their previous
versions. New task records belong in `../development/` while work is active;
archive the useful evidence when the task is complete.
