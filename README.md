# UAMC Round 1 software

ROS 2 Jazzy and Gazebo Harmonic software for lane following, obstacle stopping
and manual control of the team's RC car. ROS packages live in `ros2_ws/src`
and use the `uamc_` namespace.

Start with [setup](docs/setup.md), then follow [operation](docs/operation.md)
for simulation or the physical car. The [documentation index](docs/README.md)
links technical references, module guides and validation evidence.

Physical actuation is disabled by default. The
[commissioning checklist](docs/development/vehicle-commissioning-checklist.md)
tracks the work required before real-car operation. Simulation and software
tests do not establish hardware readiness.
